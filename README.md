# E-Commerce-Sales-Dashboard
This dashboard provides a comprehensive analysis of an e-commerce company's sales performance, showcasing customer purchasing behavior, product sales, payment method preferences, and spending patterns. It also delivers insights into total revenue generated across different states and product categories, enabling data-driven business decisions.

Tools used:
~ SQL
~ Microsoft Excel
~ Power BI

Skills Used:
~ Advanced Excel
~ SQL queries
~ DAX queries
~ Data Visualization
~ Dashboard Creation
~ Insights Generation

Data Source: Kaggle

Project Workflow:
~ Downloaded the dataset from Kaggle and imported it into Microsoft Excel.
~ Performed data cleaning and preprocessing using Excel formulas, filters, and validation techniques to improve data quality.
~ Loaded the cleaned dataset into PostgreSQL for structured storage and analysis.
~ Conducted exploratory data analysis and wrote SQL queries to extract key business insights.
~ Connected the PostgreSQL database to Power BI for visualization and reporting.
~ Utilized DAX (Data Analysis Expressions) to create calculated measures, apply business logic, and enhance data analysis.
~ Designed and developed interactive dashboards and visualizations in Power BI to effectively present insights and trends.
